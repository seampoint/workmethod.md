# Owner-controlled method changes

The owner decides changes or explicitly delegates that authority. Never edit a method autonomously. For a requested change:

1. Read the applicable method and identify its owner and any explicit delegation covering method changes.
2. Draft and show the exact change. Obtain confirmation from the owner or authorized delegate, identifying the responsible owner. A general request to review or improve a method is not confirmation of an unseen edit.
3. Apply only the confirmed change. Preserve the previous version in file history, raise the method version if a rule or decision-maker changes, and independently read back the result.
4. Record the person's decision and the authorized act in the applicable record, naming the methods and versions in force. If a step cannot be completed, disclose it and follow the unavailability procedure.

Renaming, moving or deleting a method requires specific authorization for that act. A correction entry does not by itself authorize a method edit.
