# Example tree

A small fictional team, Accounts, with one unit of work, the Harbor renewal. Point an assistant that has the `workmethod-md` skill at the `Accounts` folder and ask what is open, or ask it to record that Priya Shah promised the revised pricing table by 24 October.

- `Accounts/WORKMETHOD.md` holds the team's rules, shared by every folder below it.
- `Accounts/Harbor renewal/WORKMETHOD.md` holds the project's rules and overrides one team rule.
- `Accounts/Harbor renewal/record/` holds five entries: a commitment, a decision brought to its owner, the act that followed, a pending hand-off and a correction.
- `Accounts/Harbor renewal/research/method.md` describes a survey method. It has no method header, so an assistant treats it as information, not instructions.

Everything here is fictional.
