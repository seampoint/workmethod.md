# Contributing

This repository accepts findings, not contributions, for now. Open an issue to report a problem, an ambiguity in the specification, or an assistant that behaves differently from what the specification says. Say which assistant and app you used, what you asked, what you expected and what happened.

We are not accepting pull requests yet. The format remains a working draft; GitHub may still display the pull-request interface. Seampoint reviews findings before deciding changes. Do not include client material, personal data, credentials or private work-root paths in an issue. Use fictional minimal examples.

## Releases

Each GitHub release attaches the versioned archives from `tools/build-package.py`, `checksums.json`, and byte-identical copies of the two archives named `workmethod-md-skill.zip` and `workmethod-md-claude.zip`. The README's download links point at those two names under `releases/latest/download/`, so every release must attach them, and the release must be marked latest.
